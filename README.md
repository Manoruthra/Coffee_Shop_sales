# Coffee_Shop_sales_analysis

**Overview:**
This project analyzes coffee shop sales data using **Microsoft Excel** to uncover trends, identify peak sales periods, and evaluate performance across store locations.

**Business Questions**

1. How do sales vary by day of the week and hour of the day?
2. Are there any peak times for sales activity?
3. What is the total sales revenue for each month?
4. How do sales vary across different store locations?
5. What is the average price per order?

**Tools Used**

- Microsoft Excel:
  - Pivot Tables
  - Charts & Graphs
  - Conditional Formatting
  - Excel Formulas (e.g., `SUMIF`, `AVERAGE`, `MONTH`, `HOUR`)

**Data Preparation**
- Cleaned and formatted raw sales data
- Extracted date, time, day of week, and month from timestamps
- Added calculated columns (e.g., total price per order, time buckets)
